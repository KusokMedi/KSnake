# KSnake

Классическая игра «Змейка» для десктопа, написанная на C++ с использованием SDL2 и SDL2_ttf.

Скачать игру можно в [Releases](https://github.com/KusokMedi/KSnake/releases).

Читать на [English](README.md).

## Возможности

- Поле 20×15 с адаптивным размером окна
- Окно можно менять, но не меньше 400×360: меньшие размеры не вмещают вёрстку
  (минимум держится на всех бэкендах, включая Wayland)
- Управление с клавиатуры и мыши (выбор кнопок в меню, кликабельные кнопки на экранах)
- Пауза по `Esc`, продолжение по `Space`, повторный `Esc` — выход в меню
- Экран Game Over с результатами (счёт, время, рекорд)
- Сохранение лучшего счёта в JSON
- Проверка обновлений по релизам GitHub: в фоне при запуске (не чаще одного раза в 8 часов,
  результат хранится между запусками) и вручную из главного меню
- Пункт меню `Check for updates` становится жёлтым, если вышло обновление
- Поддержка фуллскрина (F11)
- Кросс-платформенность: Linux и Windows
- Сборочный скрипт, собирающий релизные артефакты: AppImage и Windows `.exe`
- Иконка приложения вшита в оба артефакта (исходник — `assets/ksnake.svg`)

## Управление

| Действие | Клавиши |
|---|---|
| Движение | Стрелки |
| Пауза | `Esc` |
| Продолжить из паузы | `Space` |
| В меню (из паузы / Game Over) | `Esc` |
| Рестарт после Game Over | `Space` (или `R`) |
| Фуллскрин | `F11` |

На паузе и на Game Over есть кликабельные кнопки `Continue` / `Restart` и `Menu`,
поэтому оба экрана полностью управляются мышью.
Остальные подсказки (`Enter to exit`, `Any key to return` и т.д.) тоже кликабельны:
наводишь — подсвечивается, кликаешь — выполняется это действие.

В главном меню можно управляться стрелками и `Enter`, а также мышью. Пункты меню доступны и по цифрам `1`-`6`.

## Структура

```
KSnake/
├── src/                 # исходники игры, по файлу на подсистему
│   ├── main.cpp         # точка сборки: инициализация SDL, ввод, главный цикл
│   ├── config.h         # константы поля/окна и пути к шрифтам
│   ├── game.h/.cpp      # логика змейки: поле, повороты, шаг, столкновения
│   ├── ui.h/.cpp        # шрифты, масштаб UI, layout, примитивы отрисовки, кэш текста
│   ├── screens.h/.cpp   # экраны: меню, поле, пауза, game over, credits, обновления
│   ├── update.h/.cpp    # проверка обновлений: кэш, фоновый поток, GitHub API
│   ├── storage.h/.cpp   # каталог пользователя, scores.json
│   ├── version.h/.cpp   # чтение файла VERSION
│   └── util.h/.cpp      # строки и сравнение версий
├── VERSION            # текущая версия, единственный источник истины
├── assets/font.ttf    # шрифт
├── assets/ksnake.*    # иконка игры: исходный SVG, отрендеренные размеры и .ico
├── assets/make_icons.sh # пересборка PNG/ICO иконки из assets/ksnake.svg
├── third_party/       # вендоренные заголовки (nlohmann/json) + лаунчер single-file
├── tests/             # юнит-тесты, headless-прогоны, фаззеры и оснастка
│                      # визуальных проверок (в сборку не входит)
├── build.sh           # сборка для разработки
├── build_release.sh   # релизная сборка (AppImage + Windows exe)
├── start.sh           # запуск
├── fresh-start.sh     # удалить build/, собрать заново и запустить
└── CMakeLists.txt     # конфигурация сборки
```

## Версия

Текущая версия лежит в файле [`VERSION`](VERSION) в корне репозитория.
Игра читает его при запуске из папки рядом с бинарником, а `build_release.sh` использует
его как тег релиза по умолчанию — чтобы выпустить новую версию, достаточно поменять одно число.
